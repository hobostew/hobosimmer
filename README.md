# Simmer

A family meal planner for the home screen. Keep the recipes you love, and each week Simmer plans two of them plus two
new ones it finds on the web, then writes the shopping list for all four.

Cook a new one, say whether you liked it, and the next week's suggestions get closer to what your family actually eats.

```bash
npm install
npm run dev     # no setup needed: it runs on the sample data in data/
```

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for how it's built, how new recipes are found without trusting the
model with a single fact, and how to deploy it.
